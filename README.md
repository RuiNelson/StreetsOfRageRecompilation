# Streets of Rage Recompilation

This repository is the Streets of Rage implementation submodule of the
[main Streets of Rage Project repository](https://github.com/RuiNelson/StreetsOfRageProject).

The main repository is the canonical home for the project documentation,
including legal ROM guidance, build instructions, default controls, control
configuration, keyboard shortcuts, startup flags, runtime options, discovery
workflows, and development procedures.

Please consult the [main README](https://github.com/RuiNelson/StreetsOfRageProject/blob/main/README.md)
before building or running this submodule.
